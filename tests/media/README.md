# H.264/AAC decoding regression

h264-aac.mp4 is an original one-second 64x64 color animation with silent mono
AAC, generated by make-fixture.swift through AVAssetWriter. It contains no game
or third-party media. Regenerate with:

    swift make-fixture.swift /tmp/h264-aac.mp4

The packaged native GStreamer test decodes both tracks to fakesinks. mf-video.c
then requires ten decoded NV12 frames through Wine Media Foundation. These checks
do not prove Unity's embedded-resource seek path: Not For Broadcast's menu TV and
Archive and ETS2's intro still need game checks after installation.
